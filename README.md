# TPB9000 Environmental Monitor

ESP32-based temperature and humidity monitor for the TPB9000 control enclosure.

## Hardware

- ESP32 development board
- DHT11 temperature/humidity sensor module
- SSD1306 OLED display
- 3.3V power
- I2C OLED wiring

## Planned features

- Read enclosure temperature and humidity
- Display values on OLED
- Show simple enclosure status
- Optional future fan control
- Optional future Pi status display
